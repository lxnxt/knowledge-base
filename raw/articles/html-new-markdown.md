# HTML 会成为新的 Markdown 吗？

作者：J0hn，来源：AGI Hunt

## 核心观点

Thariq Shihipar（Anthropic Claude Code 团队工程师）提出：**HTML 是新的 Markdown**——他已停止写 Markdown，全部改用 Claude Code 生成 HTML。

## 为什么 Markdown 越来越难用

### 文档越来越长

作者的习惯：给 AI 一次口喷 10 分钟数千字，让 AI 完善想法。最终产出的文档可能有 300-1000 行。

### 买菜 vs AI coding 的往返对比

去菜市场买菜，你会一次性买齐所有东西回家，减少路上的时间。AI coding 中，"路上的时间"就是 AI 说"我干完了，你来看看"后，你需要一次又一次对这些小任务进行的多次检查验收。

### 核心痛点

- 大文档接手的同事不会一行一行看
- 要么直接扔给 AI 分析开干
- 更希望有人在方案环节就进行 review，而不是完成后再发现初始方案的问题
- AI 产出的文档容易前后矛盾

## HTML vs Markdown 的核心差异

**同样的内容，不同的交付：**

- Markdown：240 行，底部写着「还有 214 行」，需要滚动阅读
- HTML：有 tab 切换、有数据图表、有关键指标高亮，扫一眼就能抓住重点

## HTML 的优势

### 1. 信息密度更高
HTML 能承载的信息类型比 Markdown 丰富太多。

### 2. 更适合阅读
一个让你滚动阅读，一个让你扫一眼就能抓住重点。

### 3. 分享门槛低
Claude Code 可以直接生成可直接分享的 HTML 页面。

### 4. 双向互动
HTML 支持交互，Markdown 只能静态呈现。

## 结论

AI 时代，**精炼的语言、更少的 token 来表达同样的内容**，是更重要的技能。HTML 作为载体，比 Markdown 更适合 AI 时代的信息传递。
